# BBUber: rules for working in this folder

A joke Uber parody for Ryan's friends, the Milford Bourbon Boys. Plain HTML, CSS and
JavaScript. No build step, no package manager, no framework. Published by GitHub Pages
from `main`, so a push is a deploy. Read `README.md` for the plain-English overview.

## Rules

1. **All content lives in `js/config.js`.** Jokes, names, prices, places, messages and
   landing page copy go there, never hard-coded in HTML or other JS. Keep its comments
   readable by a non-developer.
2. **Relative paths only.** The site runs at `/bbuber/` on GitHub Pages and may move to a
   custom domain root. Never write a path starting with `/`.
3. **Keep it unlisted.** Every page keeps `<meta name="robots" content="noindex, nofollow">`.
   No analytics tags. Do not add the Super Data Brothers GA4 tag.
4. **Keep the disclaimer.** The config `disclaimer` must stay visible in the landing footer,
   the app's About page, and the receipt: a joke, not affiliated with Uber, no car is sent.
5. **No Uber branding.** No Uber logo, wordmark artwork or typeface. The parody is in
   the name and the flow only. The accent color is bourbon amber.
6. **Keep the illusion working.** Every network call (OSRM routes, Photon search, OSM tiles)
   must have a fallback. Test with those hosts blocked after any change to `js/geo.js`,
   `js/map.js` or `js/app.js`.
7. **Drivers are always sober** in the copy. Jokes about bourbon are fine; jokes implying a
   driver drinks on the job are not.
8. **No gendered pronouns** in message templates, since real friends' names get dropped in.
9. **Friends' houses stay street-only.** Show the street name with no house number, and keep
   each pin about a block from the real house. The repo and site are public.
10. **Publish only when Ryan says "Push".** Commit locally as you go.

## Layout

- `index.html`, `css/site.css`, `js/site.js`: landing page.
- `app/index.html`, `css/app.css`, `js/app.js`: the ride app. `?embed=1` is the phone
  mockup mode; `?pickup=<placeId>&dropoff=<placeId>&tier=<id>` pre-fills a ride.
- `js/pricing.js`: fare maths shared by both. `js/geo.js`: routes, search, distance.
  `js/map.js`: Leaflet map, pins, animated cars.
- `js/idle-routes.js`: generated by `tools/bake-idle-routes.py`. Don't hand-edit.
- `icons/*.png`: generated by `tools/render-icons.sh` from the `.svg` files.
- `sw.js`: network-first offline helper. Bump `CACHE` if the file list changes.

## Testing

Preview with `python3 -m http.server` from this folder (file:// breaks the app). Drive a
full ride at phone width and at laptop width, check the receipt adds up, and check the
console is clean. Chrome's `Page.getInstallabilityErrors` should return nothing for `app/`.
